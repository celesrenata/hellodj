YouTube OAuth (music)

YouTube increasingly blocks unauthenticated (guest) requests, so Lavalink returns All clients failed to load the item and no audio plays. Authenticating with a YouTube account via OAuth fixes this. Use the device flow below: start it, open the shown URL, enter the code, and the bot pushes the refresh token to Lavalink automatically.

YouTube poToken (Bot Detection Bypass)

YouTube blocks requests it detects as bots with "Sign in to confirm you're not a bot" or "The page needs to be reloaded". A poToken (Proof of Origin) proves the request is legitimate. Click below to generate one — no browser needed.

Deezer

Deezer requires an ARL cookie from your browser session. Log into deezer.com, open DevTools → Application → Cookies → find the "arl" cookie and paste its value here. The master decryption key enables FLAC quality (premium accounts only).

Apple Music

Apple Music requires a Media API Token (developer JWT). You can obtain one from the Apple Developer portal or extract it from the Apple Music web player. Alternatively, provide a MusicKit key (keyID + teamID + private key).
